NAME

xymonlive.cgi - live browser view of Xymon status changes

 

SYNOPSIS

xymonlive.cgi [options]

 

DESCRIPTION

xymonlive.cgi serves an HTML5 dashboard that receives actual status transitions from xymond_websocket(8). It does not poll the current status board and does not read history or allevents files. The dashboard displays only recent changes.

The gateway keeps a bounded transition ring in memory. A newly connected or reconnected browser receives that ring and then receives new transitions as they happen. The browser deduplicates replayed entries by gateway generation and sequence number.

The ring is not a durable history. It starts empty when the gateway restarts; browsers detect the new generation and discard entries from the previous process. No checkpoint is read or written.

The client can filter events by host, service, or message text and by event type: status transition, disable comment, or acknowledgement comment. It keeps up to 500 events in memory and can render 25, 50, 100, 250, or all 500 rows. Status-message text can be hidden without removing it from client-side filtering.

The webserver must proxy $XYMONSERVERCGIURL/xymonlive-ws to the loopback gateway. The generated Apache configuration includes guarded proxy directives; enable the Apache proxy and proxy_wstunnel modules to use them.

An upgrade preserves an existing locally managed xymon-apache.conf. Merge the Xymon Live ProxyPass directives from the generated configuration into that file when upgrading an existing installation.

 

OPTIONS

--env=FILENAME
Load the Xymon environment from FILENAME.
--area=NAME
Load environment settings for the named area.
--debug
Enable debugging output.
